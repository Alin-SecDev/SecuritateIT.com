Step 4 Configure SSH on Routers YELLOW1 and RED1
YELLOW1
enable
admin
configure terminal
username admin password admin
ip domain-name learn_network
crypto key generate rsa
1024
ip ssh version 2
line vty 0 4
login local
transport input ssh

RED1 repeat the same steps as in YELLOW1
