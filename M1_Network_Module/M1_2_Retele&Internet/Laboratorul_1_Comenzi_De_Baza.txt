We have two network blue and red and we must connect them trough 2 routers to communicate from one to another. 
The template of the network is provide. 

First task is to cable the components of the two LAN's and one WAN

Second task is to assign the ip addresses for the routers and pc
Red ip domain is: 172.16.0.0/24
Green ip domain is: 89.12.0.0/24
Blue ip domain is: 192.168.0.0/24

Third task is to set hostname and enable passwords. 

I completed the first task by dragging the cables 

For the second task:
I will start with the red network with the router RED 1

enable
configure terminal
hostname RED1
enable password admin
interface Gig0/0
ip address 172.16.0.1 255.255.255.0
no shutdown
do show ip interface brief
end
exit

RED_PC1
On IP Configuration we set:

IPv4 Address 172.16.0.2
Subnet Mask 255.255.255.0
Default Gateway 172.16.0.1

RED_PC2
IPv4 Address 172.16.0.3
Subnet Mask 255.255.255.0
Default Gateway 172.16.0.1

Now we test the ping to the router and between the pc's on the RED network
